# 🎬 La Traviata — Étude de la mise en scène

Lecteur web interactif pour étudier la **mise en scène de La Traviata** — rôle du **Marchese d'Obigny**.

> 🎭 *Production La Traviata — Captation du 13 juin 2025*

## 🚀 Utilisation

**En ligne (recommandé)** : ouvrir directement [index.html](index.html) dans un navigateur (Safari, Chrome, Firefox).

**Sur tablette** : compatible iPad, Android, iPhone — interface optimisée tactile.

## ✨ Fonctionnalités

- 🔍 **Zoom** 1× → 5× sans interrompre la lecture (pinch sur tablette, molette sur PC)
- 🗺️ **Mini-map** quand on est zoomé
- ⏯ **Vitesse** 0.25× → 2× + lecture image par image
- 🔁 **Boucle A → B** pour répéter un mouvement
- 📍 **Repères de scène** cliquables sur la timeline
- 📝 **Notes personnelles** par moment (privées, sauvegarde locale)
- 📷 **Captures photo** avec timecode (galerie privée par appareil)
- ⛶ **Plein écran** natif

## 🖐️ Gestes tactiles (tablette)

| Geste | Action |
|---|---|
| Tap simple | Play / Pause + afficher contrôles |
| Double tap | Reset zoom |
| **Tap long** | 📝 Ajouter une note rapide |
| Pinch 2 doigts | Zoom |
| Drag 1 doigt (zoomé) | Déplacer la zone |

## ⌨️ Raccourcis clavier (PC)

| Touche | Action |
|---|---|
| `Espace` | Play / Pause |
| `← →` | −10s / +10s |
| `Shift + ← →` | −1s / +1s |
| `, .` | Image par image |
| `+ −` | Zoom |
| `R` | Reset zoom |
| `A / B / L` | Points de boucle / activer |
| `F` | Plein écran |
| `P` | Capturer photo |
| `N` | Nouvelle note |
| `M` | Ouvrir le panneau notes |
| `1, 2, 3` | Changer de clip |
| `0–9` | Sauter à 0%, 10%... 90% |

## 🔒 Vie privée

- **Aucune donnée n'est envoyée à un serveur**
- Toutes les **notes**, **photos** et **repères édités** sont stockés **localement** dans le navigateur de chaque appareil
- Chaque utilisateur a sa propre copie privée — personne ne voit les notes des autres
