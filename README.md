## ✨ Fonctionnalités

- 🔍 **Zoom 1× → 5×** (pinch-to-zoom sur tablette, molette sur PC)
- 🖱️ **Drag** pour suivre un personnage en plan rapproché
- 🗺️ **Mini-map** pour se repérer quand on zoome
- ⏯ **Lecture vitesse 0.25× → 2×** + frame-by-frame
- 🔁 **Boucle A → B** pour répéter un mouvement
- 📍 **Marqueurs cliquables** sur les moments clés
- 📝 **Notes personnelles** par moment (sauvegarde locale)
- ⌨️ **Raccourcis clavier** complets
- 📱 **Optimisé tablette** (iPad, Android, iPhone)
- ⛶ **Plein écran** natif

## 🎯 Compatibilité

- ✅ iPad / iPhone (Safari, Chrome)
- ✅ Tablette Android (Chrome, Firefox)

1. Téléchargez le ZIP du dépôt
2. Décompressez
3. Ouvrez `index.html` dans un navigateur (Chrome / Safari recommandés)

Aucune installation requise. Tout fonctionne en local.

## ⌨️ Raccourcis clavier

| Touche | Action |
|---|---|
| `Espace` | Play / Pause |
| `← →` | −5s / +5s |
| `Shift + ← →` | −1s / +1s |
| `, .` | Image par image |
| `+ −` | Zoom |
| `R` | Reset zoom |
| `A / B` | Marquer points de boucle |
| `L` | Activer / désactiver boucle |
| `F` | Plein écran |
| `0–9` | Sauter à 0%, 10%... 90% |
| `1, 2, 3` | Changer de clip |

## 📱 Sur tablette

- **2 doigts** = zoom (pinch)
- **1 doigt** = déplacer la zone zoomée (quand zoomé)
- **Tap** = bouton / lecture / pause
- **Double-tap** = reset zoom
- **Bouton 📋 Notes** en haut = afficher la sidebar
